# Monitoramento de Projetos — DTD / SETIS / SES-DF

Esta pasta centraliza o monitoramento público dos projetos conduzidos pela
Diretoria de Transformação Digital (DTD) da Secretaria Executiva de Tecnologia
da Informação em Saúde (SETIS) da Secretaria de Estado de Saúde do
Distrito Federal (SES-DF).

## Como funciona

- A documentação interna de cada projeto é mantida em repositório privado,
  acessível apenas aos profissionais diretamente envolvidos.
- Este espaço publica **somente** uma visão panorâmica curada, com linguagem
  acessível a públicos externos à instituição.
- Novos projetos entram nesta lista apenas mediante autorização explícita
  do Diretor de Transformação Digital.
